Position, not personality

Clinical structures

Obsession and hysteria are neuroses. Perversion is a different relation to the law. Psychosis is a different relation to the Symbolic. The charts add a working fifth: the ethical / sinthomatic subject — not a structure of illness, but a way of occupying one’s own desire.

The original footnotes repeat: this is a clinical-structural sketch. Individuals are not boxes. A table is a map, not a verdict.

One process, four (plus one) realizations

The UML charts treat subjectivation as an interface every structure must implement: meet the Real, make meaning, prove a place, bind jouissance, sustain an existence. The “class” (obsessive, hysteric, perverse, psychotic) realizes that interface in its own idiom.

Structure Avoids / meets the Real by Typical object Tip-off in the UML charts
Obsessive Rules, delay, control, thought Control object (ritual, work, plan, calendar) Intolerance of uncertainty; hunger for control
Hysteric Questioning; keeping desire open Gaze object (look, love, being wanted) Search for the answer of desire; need to appear
Perverse Staging the Other’s jouissance Fetish object (covers lack with a thing or scene) Will to manage the Other’s desire as a scene
Psychotic A private meaning-order (or its collapse) Stabilizing object (voices, systems, numbers, faith) Strain in holding a shared, consistent world
Ethical / sinthomatic Admitting lack and knotting it Sinthome object (work, art, a chosen practice) Loyalty to one’s desire without making others into tools

Fragile cycle vs creative cycle

Most structure pages end with two arrows. The upper arrow is the structure’s default loop (control, questioning, manipulation, fragmentation). The lower arrow is the sinthomatic loop: produce meaning from inside, share a style, turn trauma, put the symptom to work, write a formula, live a knot.

That second arrow is why the archive is not only a pathology atlas. It is a map of possible ethical exits that do not require becoming a different species of subject.
