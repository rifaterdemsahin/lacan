Why this repo is a site

About and rationale

The repository began as a folder of WhatsApp image exports with timestamps for names. Those files were already a curriculum. This site names them, explains them, and makes them searchable.

Rationale

  1. The images are the primary text. They are dense teaching charts (Turkish, one English twin) covering a full Lacanian clinic: structures, a six-step cycle, objects, parents, jouissance, and even a UML sketch. Leaving them as WhatsApp Image 2026-07-29 at 10.34.25 (3).jpeg hid that curriculum.
  2. Filenames should be semantic. A reader, a search box, and git history all benefit from names that say what the chart is. One exact duplicate was dropped.
  3. Charts need a discursive layer. An infographic is a map. These HTML pages are the legend: what the arrows mean, how RSI sits under the columns, where the ethical row is not a diagnosis.
  4. One process, many zooms. Index → cycle → structures → each structure → objects / parents / dopamine / UML. That is the same content at different resolutions, which matches how the original images were drawn (overview, then a row, then a companion table).
  5. Search belongs at the top. Lacanian vocabulary is easy to lose. The header search is a client-side index over every page title, excerpt, and keyword. Press /.
  6. This is teaching, not diagnosis. The charts themselves print that warning. The site repeats it so a vivid table is not used as a personality test.
